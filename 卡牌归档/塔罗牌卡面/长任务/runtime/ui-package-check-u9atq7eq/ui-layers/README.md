# 通用花色与点数图层

独立于197项卡面队列的17项素材：4个花色、A/2～10/J/Q/K共13个点数。进度只以[state.json](state.json)的`done`及[manifest.json](manifest.json)为准；候选文件不是完成数。

2026-10-21已完成17/17项离线验收。打开[组合预览](preview.html)可检查任意点数和花色叠加、深浅底与实际UI尺寸；另有[17项总览](图层总览.png)及[52种组合](52种组合.png)。[完整验证报告](verification.json)确认17项PNG/SHA/Alpha、52组合可见像素不相交，以及红桃和点数2原字节复用。

独立[总体验收](总体验收.md)已实际查看两张总览并通过：四花色及13点数齐全，A/10/J/Q/K在实际UI尺寸可辨，52组合没有挤压。浅底的香槟金点数对比较轻；该结论覆盖离线深浅纯色背景，游戏内效果尚未验证。

## 文件和职责

- `38x34/`：验收后的RGBA PNG，显示尺寸19×17；点数合成位置(8,8)，花色(8,38)。
- `原图/`：新生成项的原始PNG字节；旧红桃和2是已验收38×34原文件的原字节副本，并非还原高清原图。
- `候选/<ID>/vN.*`：不可覆盖的原图、38×34导出及版本记录；失败版本也保留原因。
- `逐项记录/`、`提示词/`、`参考图/`、`检查图/`：每项来源、实际prompt、返回prompt、生成ID、SHA、Alpha、归一化与人工视觉结论。
- `layer_io.py`：仅本地图像I/O、Alpha检查、等比缩放/透明留边、记录和独立检查点；复用长任务`production_io.py`读取已有原生结果，不调用API、不生成字形、不写卡面队列。
- `build_preview.py`：只组合已验收PNG，生成离线HTML和总览；预览中的文字标签与纯色检查背景不是资源内容。
- `52种组合.png`：四花色×十三点数的实际19×17 UI图层角落合成，每格并列深浅底；不是新生成的资产，也不表示这些组合均为实体牌。

点数字形按自然比例校准至约28px可见高、视觉中心x=16、基线附近y=30。两位数10完整容纳，不横向压缩。花色参考旧红桃的(5,4,33,30)自然边界，等比缩放至不超过28×26并居中。所有素材保留真实Alpha，不把棋盘格烘焙进去。

已验收的10按自然双字符比例在30px宽内等比缩放，可见边界为`(1,6,31,30)`、30×24，基线y=30及视觉中心x=16与单字符一致。没有为了凑28px高而横向压缩；实际19×17检查仍明确读作10，0的字腔透明。

## 恢复

从仓库根使用`.venv-card-atlas/Scripts/python.exe -B -X utf8`运行脚本。先`layer_io.py status`读检查点；`prepare ID --attempt N`返回唯一标签、一张小JPEG、冻结提示词及既有原生结果。已有结果先`save`，禁止盲目重生成。每项/每次重试使用`fork_turns=none`独立上下文，仅一次原生`image_gen`请求；先落盘，再实际看检查图，再`review --note`或`review --reject --note`。父流程检查后`accept`。旧图用`reuse suit_heart`和`reuse rank_2`，仍须实际看图、review、accept。

允许仅透明裁切、等比缩放与留边平移；禁止程序绘制字形代替原生生成。`原图`与候选拒绝覆盖不同字节；改图必须开新attempt。429时保留结果和检查点，不切CLI/API。

归一化以`Alpha>8`的可见边界加4个原始像素边缘裁切，再等比缩放，避免远处`Alpha=1..8`近透明杂点把有效符号缩小。方块v2原图正确，但旧非零Alpha包围框导致导出可见高度仅约20px；`reexport suit_diamond --attempt 2 --new-attempt 3`复用同一原始PNG、实际提示词和生成ID，校正导出高度为26px后验收。候选版本可以是明确标记`derivation.newGeneration=false`的重新导出；不冒充一次新生成，旧版本原字节保留。`reexport`拒绝覆盖已有版本或已提交项。

`来源原图/`另外恢复了既有红桃及已确认偏移点数2的历史高清原生PNG，附原生成ID、会话定位和SHA。它们只用于高清样式参考与溯源；已确认38×34成品仍原字节复用，不被恢复原图替换。

早期已提交红桃复用记录保留当时的说明，不追写修改已验收记录；后续恢复的高清来源以`来源原图/*.json`为准。新生成项使用这些原图压成一张228×204内的JPEG参考，未把38×34小图放大充当高清细节。

当前只交付离线图层，未修改游戏、atlas或asar。最终卡面合并包应一并包含17项与布局映射，不能把它们计入197项底图完成数。

本交付副本的图层制作工具源快照位于`../inputs/tools/ui-layers/`，需在原归档工作区运行；本目录可直接使用PNG、manifest及组合预览。来源记录中的绝对路径仅用于历史溯源。
