# 闪 · v5 四花色样张

四张均由 OpenAI 内置图像工具分别生成，沿用v4的卡面结构。完整提示词在“提示词”文件夹中。

- `四花色对比.png`：四张并排对比。
- `preview.html`：可查看大图，并切换游戏尺寸。
- `大图/`：红桃、方块、黑桃、梅花四张大尺寸PNG。
- `186x260/`：四张186×260、不透明RGBA PNG，文件名为 `Shan_heart.png`、`Shan_diamond.png`、`Shan_spade.png`、`Shan_club.png`。
- `generation-record.json`：输入、生成记录、文件映射、尺寸和SHA-256。

这里只生成“闪”的四花色设计样张，尚未替换游戏素材或合回图集。当前游戏的四个花色共用Shan底图，因此这四份样张的文件名用于区分设计，不表示客户端已经按花色自动切换。
