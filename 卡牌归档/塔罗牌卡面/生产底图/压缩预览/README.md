# 单卡小文件预览

用户最新反馈186×260放大模糊并要求省token：本目录现作为默认高清卡面输出（目录沿用旧名），最大744×1040、单张≤200 KB；相邻186×260 PNG仅作原图集兼容。两种尺寸来自同一次生成。已停止每卡自动更新预览页/拼图，旧浏览页仅为首批历史快照；准确当前清单以manifest为准。`compact_assets.py`默认只同步必要图片/清单，只有显式`--page`才制作HTML。

打开[卡面浏览页](../preview.html)。本目录为已提交生产卡面的WebP查看副本，每张不超过200,000字节，最大744×1040，保持自然比例。实际游戏素材仍使用相邻`186x260/`中的无损RGBA PNG，并检查同样的单张大小上限。

`manifest.json`记录每个副本的大小、尺寸、质量、SHA及原始PNG的SHA；`长任务/compact_assets.py`只处理主检查点已提交项，`progress.py accept/sync`自动调用。已存在且来源/哈希相符的副本直接复用，不重复压缩；遇到不同字节的同名文件拒绝覆盖。原始PNG、正式186×260 PNG、单卡记录和完成检查点的已提交哈希不变。

原生图像工具的原始输出可能仍为约2 MB，必须先保存作溯源；本流程不能保证用提示词把原生返回体固定为指定字节数。常用查看和单卡返回使用这里的小文件。每次生成仍只有一个小参考/目标，压缩副本不替代原始PNG作为下一张生成的高清样式来源，避免有损压缩累积。

首批17张已检查：压缩副本最大178,018字节，总计2,504,360字节，对应原始PNG总计38,668,867字节；186×260生产PNG最大119,558字节。全部可解码，尺寸/哈希/上限通过，缓存重跑不改变副本，全部已提交原件哈希未变。已实际对照寒冰剑、诸葛连弩、紫騂、无中生有的原图和压缩版，缩小显示时文字、徽记与整体布局保持可辨；对照图在`长任务/runtime/compact-preview-check.jpg`。这里的WebP是有损查看副本，不宣称逐像素等同原图。

首批使用WebP method6；后续新文件用method4减少编码耗时，仍执行相同尺寸、质量阶梯及200 KB上限。旧副本保持字节不变；准确当前数量和统计以manifest为准。
