# 军争卡牌

本目录按当前官方配置的“身份→军争”（Model=1、ModelTab=2）筛选：161张实体牌，实际引用44张原始底图，44份PNG均放在本目录。牌ID 1～161的资源名、花色、点数及重复数量，已逐项与军争图鉴核对一致。

- `preview.html`：按牌名或纹理名搜索、查看图片。
- `161张牌对应表.csv`：完整161个牌ID到图片的映射。
- `卡面清单.csv`：每种底图的对应张数。
- `texture-mapping.json`：原始文件名、图集坐标、scale、共享别名、牌ID及复制时文件哈希。

花色和点数由游戏另行绘制，不在这些原始底图上。本次没有从其他模式补图凑数，也没有覆盖原来的完整图集文件夹。

编辑时保留PNG文件名、像素尺寸及透明通道。完成后把修改后的同名PNG复制到上一层的 `cards/` 文件夹，再运行上一层 `merge.cmd`，即可按原始纹理位置合回。此处的副本不会自动同步到 `cards/`。

藤甲 `TengJia_png.png` 与完整图集中的 `TengJia2_png.png` 共享同一坐标：只改藤甲这份即可，合回后两个纹理名都会引用修改结果；同组不同修改会由合并工具报冲突。

配置来源及获取时间见 `texture-mapping.json` 的 source 字段；保留了独立目录和原始图集的对应关系。
